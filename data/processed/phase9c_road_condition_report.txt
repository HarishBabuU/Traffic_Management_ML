  PHASE 9C - ROAD CONDITION LAYER REPORT
============================================================================
  Mode used  : mock
  Records    : 8

  1. WHAT PHASE 9C DOES
     A configurable road-condition data layer producing
     normalized, explainable per-road outputs: surface /
     construction / closure / flooding / incident status plus
     overall_road_condition, road_risk, confidence and a reason.
     It is independent of Phase 9A (traffic), Phase 9B (weather)
     and the traffic videos; NO association is made to any video.

  2. INPUT SCHEMA
     config/road_condition_config.json -> test_roads[] and
     manual_records[] (plus programmatic input). Required fields:
     road_id, road_name, latitude, longitude; optional status
     fields default to UNKNOWN and are normalized.

  3. SUPPORTED DATA MODES
     live   : external source (NOT configured - never fabricated)
     manual : user-supplied records from config/manual_records
     mock   : deterministic, reproducible test records
     unknown: any record that cannot be sourced (data_mode=unknown)

  4. ROAD-CONDITION CATEGORIES
     road_surface: GOOD | MODERATE | POOR | UNKNOWN
     construction: NONE | ACTIVE | UNKNOWN
     closure     : OPEN | PARTIAL | CLOSED | UNKNOWN
     flooding    : NONE | POSSIBLE | SEVERE | UNKNOWN
     incident    : NONE | REPORTED | UNKNOWN
     overall     : GOOD | MODERATE | POOR | RESTRICTED | UNKNOWN
     road_risk   : LOW | MODERATE | HIGH | UNKNOWN

  5. EXPLAINABLE RISK LOGIC (deterministic points)
     surface GOOD=0 MODERATE=1 POOR=3 UNKNOWN=0(unknown)
     construction NONE=0 ACTIVE=2
     closure OPEN=0 PARTIAL=4 CLOSED=6
     flooding NONE=0 POSSIBLE=1 SEVERE=5
     incident NONE=0 REPORTED=2
     CLOSED/PARTIAL closure or SEVERE flooding -> RESTRICTED.
     else penalty: 0=GOOD, 1-2=MODERATE, 3-4=POOR, >=5=RESTRICTED.
     risk: RESTRICTED/POOR=HIGH, MODERATE=MODERATE, GOOD=LOW,
           UNKNOWN overall=UNKNOWN risk.

  6. HOW UNKNOWN DATA IS HANDLED
     - Missing fields become UNKNOWN (never GOOD).
     - A GOOD label is suppressed whenever any field is UNKNOWN.
     - All-five UNKNOWN -> overall UNKNOWN and risk UNKNOWN.
     - Confidence falls x0.80 per UNKNOWN field, plus x0.90 for
       manual and x0.60 for mock data (test data is not treated
       as real-world evidence).

  7. TEST/MOCK LIMITATIONS
     Mock records are DETERMINISTIC TEST DATA with fictional
     coordinates (labelled TEST-RD-*, lat/lon near null island).
     They exercise every scoring branch but describe NO real
     road; they must never be presented as real-world conditions.

  8. LIVE DATA STATUS

     The live branch raises RoadConditionError instead of
     fabricating data; live records will be produced only once
